# ADR-0011: Public market-data sources, completeness, and the OKX candle decision

Status: accepted (M2)

**Observations.** Normalised public events become durable, append-only `market_observations` carrying venue, canonical and native symbol, exchange timestamp, local ingestion timestamp, source (`LIVE` / `BACKFILL`), connection id and a completeness flag; both timestamps are UTC and kept. Only CLOSED 1-minute candles feed the simulation; quotes are sampled once per minute for spread context; trades are used only for freshness. Continuity is checked per (venue, symbol): a jump in the 1-minute open time opens a `market_data_gaps` row; a late/out-of-order candle that completes the hole closes it; REST backfill (bounded to ~1000 minutes) closes it or marks it `UNRECOVERABLE`. **Delivery completeness is never claimed** where exchange sequence continuity cannot be proven — only "all minutes present" is asserted, per bar.
**Session bars** (5 m / 15 m / 1 h) are aggregated from complete 1-minute buckets only (reusing the M1 rule: no partial buckets, no interpolation). Warm-up history comes from public REST (closed bars only).
**Binance.** Public market-data hosts only (`data-api.binance.vision`, `data-stream.binance.vision`); `kline_1m`, `trade`, `bookTicker` streams; the 24 h connection rollover is handled by the standard reconnect with equal-jitter exponential backoff (a `Reconnected` marker opens a gap check). No private/user streams, no trading API.
**OKX — verified on 2026-11-12 from this machine.** Public REST works; public WebSocket `wss://ws.okx.com/ws/v5/public` delivers `tickers` and `trades` (the old `:8443` port is being retired by OKX, notice 64010, so the adapter uses 443). **The `candle1m` channel is rejected on the public endpoint** (error 60018, "wrong URL or channel") because OKX serves candles on the *business* WebSocket, a path the egress policy deliberately forbids (`/ws/v5/business`, which also hosts authenticated channels). Decision: OKX 1-minute candles come from the **public REST** `market/candles` endpoint polled every 15 s, using only candles the exchange marks `confirm=1`; history uses public `market/history-candles` pages; the WS supplies freshness and spread. The egress allow-list was **not** loosened. A venue that fails verification (REST time + public instrument rules) is DISABLED with an explicit stored reason, keeps its virtual cash uninvested and is never bypassed.
**Rate limits.** `PublicHttp` raises `RateLimited` on 418/429 (never retries in a loop); the OKX poller issues 3 calls per 15 s; gap backfill handles ≤ 3 gaps per venue per 30 s with a pause between calls.
**Clock.** Per-venue offset measured every 60 s (midpoint-corrected); drift beyond the safe limit opens a CLOCK_DRIFT incident; the offset is stored on the feed row.
**Rules and fees.** Instrument rules are the *current* public snapshot (stored in `market_rules_versions`, source LIVE) and fee schedules remain the M1 *assumed, unverified* profiles (residual R-11).
